UPDATE WAJIB UNTUK CHECKLIST PORTOFOLIO

Agar checklist berubah otomatis setelah upload, Google Apps Script harus memakai Code.gs versi V8 ini.

Langkah:
1. Buka Google Apps Script yang dipakai untuk upload.
2. Hapus semua isi Kode.gs.
3. Paste isi file apps-script/Code.gs dari paket ini.
4. Simpan.
5. Jalankan function testSetup sekali untuk otorisasi Drive.
6. Klik Terapkan > Kelola deployment > Edit/pensil.
7. Pada Versi pilih Versi baru.
8. Klik Terapkan.
9. Pastikan Web App URL tetap dipakai di script.js.

Setelah itu upload file dari website. Pesan yang benar:
Upload berhasil. Checklist sudah diperbarui dan file tersimpan di Google Drive.
