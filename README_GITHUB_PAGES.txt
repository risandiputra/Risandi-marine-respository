File ini adalah versi yang sudah menampilkan kembali menu Portofolio Kinerja lengkap dengan:
- Dashboard checklist bukti portofolio
- Form upload dokumen
- Kode akses arsip
- Integrasi Google Apps Script Web App
- Link Google Drive tujuan

Cara upload ke GitHub Pages:
1. Extract ZIP.
2. Upload isi folder ini ke repository GitHub.
3. Pastikan file index.html berada langsung di root repository.
4. Buka Settings > Pages > Deploy from branch > main > /root.
5. Tunggu proses publish.

Menu upload berada di:
Portofolio Kinerja > Tambah / Upload Bukti
