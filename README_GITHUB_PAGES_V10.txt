WEBSITE V10 - INFOGRAFIS SCIENCE FIXED

Versi ini memakai menu Infografis Science sebagai pengganti section checklist lama.

File yang harus diupload ke GitHub repository:
- index.html
- styles.css
- script.js
- terima-kasih.html
- assets/
- .nojekyll

Cara update:
1. Extract ZIP.
2. Masuk ke repository GitHub.
3. Hapus file lama jika perlu, terutama index.html, styles.css, script.js.
4. Upload semua isi folder hasil extract ke root repository, bukan folder ZIP-nya.
5. Commit changes.
6. Tunggu 1-5 menit.
7. Refresh website dengan Ctrl+F5 / Command+Shift+R atau buka Incognito.

Menu final:
Beranda, Tentang, Keahlian, Fokus Riset, Publikasi, Berita Riset, Infografis Science, Kontak.
